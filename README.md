# Getting and Cleaning Data Project

This project demonstrates how to clean and prepare data using R.

## Files included:

* run_analysis.R: Script to clean the dataset
* tidy_data.txt: Final tidy dataset

## Steps performed:

1. Merged training and test datasets
2. Extracted mean and standard deviation features
3. Applied descriptive activity names
4. Labeled variables clearly
5. Created a tidy dataset with averages
